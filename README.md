# LEDKASA

Profesyonel LED ekran kasaları ve bağlantı ekipmanları vitrin sitesi.

## Stack

- Astro (static)
- Netlify (`netlify.toml`, Forms, headers)

## Komutlar

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Sayfalar

- `/` — ana vitrin
- `/urunler` — katalog
- `/urunler/[slug]` — ürün detay
- `/iletisim` — teklif formu (Netlify Forms)
